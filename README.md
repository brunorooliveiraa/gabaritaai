# 🎓 Gabarita.ai

**🌐 Acesse o portal online: [gabaritaai.netlify.app](https://gabaritaai.netlify.app/)**

O **Gabarita.ai** é um portal completo desenvolvido para descomplicar a graduação dos estudantes universitários. Criado como um ambiente colaborativo de alunos para alunos, a plataforma permite que o conhecimento circule livremente, oferecendo apoio para estudos, inspiração para criação e uma comunidade unida.

## 🚀 Funcionalidades

* **Banco de Provas:** Acesso a provas antigas para melhor preparação acadêmica.
* **Projetos Acadêmicos:** Portfólio para explorar e se inspirar com projetos desenvolvidos por outros estudantes.
* **Comunidade:** Espaço de conexão, networking e troca de experiências.

## 🛠️ Tecnologias Utilizadas

* **Front-end:** HTML5, CSS3, JavaScript (Hospedado no Netlify).
* **Back-end e Banco de Dados:** Firebase.
* **Integração e Scripts de Dados:** Python.
